# REST API Strategy (PSA-1)

**Status:** Implemented baseline for PSA-1  
**Related tasks:** PSA-0103

## Conventions

- Transport: HTTP REST JSON.
- Versioned prefix: `/api/v1`.
- OpenAPI UI: `GET /api/v1/docs`.
- OpenAPI document: `GET /api/v1/openapi.json`.
- Correlation header: `x-correlation-id` (generated by API if absent; echoed on responses).

## Shared contracts

Source of truth: `@sounds-university/contracts`.

- `ApiErrorBody`: `{ code, message, correlationId, details? }`
- `HealthResponse`, `ReadyResponse`

Frontend typed access: `@sounds-university/api-client`.

## Error model

All non-2xx JSON errors use `ApiErrorBody`. Client-facing messages are safe. Stack traces and internal exception names are logged server-side only.

## Evolution

Additive OpenAPI changes are preferred. Breaking changes require a new version prefix or an accepted ADR. Do not silently diverge request/response types between apps and `packages/contracts`.
